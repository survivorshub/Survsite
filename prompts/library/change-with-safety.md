# Prompt: cambiar algo con seguridad

Usa este prompt para introducir cambios pequeños y bien delimitados sin romper el estado actual del proyecto.

## Prompt

Haz un cambio pequeño y seguro en este repositorio.

Requisitos:
- revisar el estado actual del repositorio antes de editar nada;
- identificar el alcance del cambio y evitar tocar más archivos de los necesarios;
- mantener la compatibilidad con lo que ya existe;
- añadir o actualizar pruebas o comprobaciones cuando sea posible;
- validar el resultado con una comprobación real antes de terminar;
- si el cambio afecta a publicación o despliegue, dejar el flujo preparado para PR.

## Resultado esperado

- un cambio mínimo y comprensible;
- sin regresiones evidentes;
- validado con una comprobación real.
