# Prompt: cambiar algo con seguridad

Usa este prompt para introducir cambios pequeños y bien delimitados sin romper el estado actual del proyecto.

## Prompt

Haz un cambio pequeño y seguro en este repositorio.

Requisitos:
- revisa el estado actual del repositorio antes de editar nada;
- identifica el alcance del cambio y evita tocar más archivos de los necesarios;
- mantén la compatibilidad con lo que ya existe;
- añade o actualiza pruebas o comprobaciones cuando sea posible;
- valida el resultado con una comprobación real antes de terminar;
- si el cambio afecta a publicación o despliegue, deja el flujo preparado para PR.

## Resultado esperado

- un cambio mínimo y comprensible;
- sin regresiones evidentes;
- validado con una comprobación real.
