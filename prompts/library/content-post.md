# Prompt: crear o editar un post del blog

Usa este prompt para añadir o modificar contenido del blog sin romper la estructura de Jekyll ni el flujo de publicación.

## Prompt

Crea o actualiza un post en el blog de forma consistente con el estilo del proyecto.

Requisitos:
- revisar los posts existentes para mantener tono y estructura;
- usar el formato correcto de front matter;
- asegurarse de que el contenido sea correcto y coherente;
- validar que el post no rompa la compilación del sitio;
- si se añaden imágenes o enlaces, comprobar que funcionen correctamente;
- dejar el cambio preparado para PR si afecta a la publicación.

## Resultado esperado

- un post bien formado y consistente;
- sin errores evidentes de estructura ni compilación;
- listo para revisión y publicación.
