# Prompt: cambiar el tema del sitio

Usa este prompt cuando quieras modificar la apariencia visual del sitio sin introducir cambios complejos ni sobrecargar al usuario con demasiados detalles.

## Prompt

Cambia el tema visual del sitio de forma sencilla y coherente.

Requisitos:
- primero, pregunta al usuario por sus preferencias generales de estilo;
- limita la conversación a unas pocas decisiones clave, como tono visual, nivel de formalidad, contraste y sensación general;
- no pidas demasiadas opciones ni detalles técnicos innecesarios;
- analiza el tema actual y propón un cambio razonable que mantenga la estructura y usabilidad del sitio;
- evita romper la navegación, el contenido existente ni la compatibilidad del blog;
- si el cambio afecta a estilos, layout o assets, valida que el sitio siga compilando correctamente;
- deja el cambio preparado para revisión mediante PR.

## Resultado esperado

- una propuesta visual coherente con las preferencias generales del usuario;
- cambios limitados y fáciles de revisar;
- sin regresiones evidentes en el sitio.
