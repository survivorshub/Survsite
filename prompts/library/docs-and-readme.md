# Prompt: actualizar documentación

Usa este prompt para modificar documentación del proyecto manteniendo coherencia con el flujo real y con la información publicada.

## Prompt

Actualiza la documentación del proyecto para que refleje el estado real del repositorio.

Requisitos:
- revisar los documentos existentes antes de editar;
- mantener la información alineada con el flujo actual de trabajo y despliegue;
- evitar contradicciones entre README, prompts y procesos reales;
- validar que los enlaces y referencias sigan siendo correctos;
- si el cambio afecta al proceso de publicación, dejar el flujo listo para PR.

## Resultado esperado

- documentación consistente y útil;
- sin contradicciones evidentes;
- preparada para revisión.
