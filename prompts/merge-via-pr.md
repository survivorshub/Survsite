# Prompt: llevar un cambio a main vía PR

Usa este prompt cuando quieras pedir que un cambio llegue a main mediante un Pull Request.

## Prompt

Lleva este cambio a main mediante un Pull Request, siguiendo el flujo habitual del repositorio.

Requisitos:
- crear una rama de trabajo desde main;
- implementar el cambio de forma limitada y clara;
- validar el resultado con una comprobación real;
- subir la rama al remoto;
- abrir un PR hacia main;
- dejar el cambio preparado para revisión y fusión.

Importante:
- no hacer merge directo a main;
- respetar el flujo de PR del proyecto.

## Resultado esperado

- un branch con el cambio;
- un PR abierto contra main;
- el cambio listo para revisión y posterior fusión.
