# Prompt: llevar un cambio a main vía PR

Usa este prompt cuando quieras pedir que un cambio se lleve a la rama principal mediante un Pull Request, siguiendo el flujo habitual del repositorio.

## Prompt

Lleva este cambio a main mediante un Pull Request, siguiendo el flujo habitual del repositorio.

Requisitos:
- crea una rama de trabajo a partir de main;
- haz los cambios necesarios en el repositorio;
- valida el resultado con la comprobación pertinente (por ejemplo, compilación o build);
- sube la rama al remoto;
- abre un PR hacia main;
- deja el cambio preparado para revisión y fusión.

Importante:
- no hagas merge directo a main;
- sigue el flujo de PR del proyecto;
- si hay cambios pendientes, descríbelos de forma clara en el PR.

## Resultado esperado

- un branch con los cambios;
- un PR abierto contra main;
- el cambio listo para revisión y posterior fusión.
